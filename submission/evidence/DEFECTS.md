# Defect and Anomaly Register

## Purpose

Records every defect, anomaly or contradiction discovered while executing preflight and drafting artefacts 01–07, independent of the disclosed inject catalogue. Each entry states how it was found, its current status and which artefact/evidence file relies on it. This register is additive to `starter/baseline_diagnostics.py`'s four seeded findings, not a replacement for them.
