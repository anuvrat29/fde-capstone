# Project AEGIS-INSURE — Workshop-Ready Insurance AI FDE Capstone v2

A challenge-only, fully synthetic, offline-capable capstone for Forward Deployed Engineers working in a global composite insurer and reinsurer.

## Package scale

- 96 disclosed and cross-linked injects.
- Three mandatory authority-bounded workflows.
- 202 supplied operational CSV datasets plus workshop metadata and coverage maps.
- 37 mixed-authority knowledge documents.
- 18 reproducible public evaluation fixtures without expected answers.
- Four machine-enforceable response contracts with positive and negative tests.
- 32 structured participant artefact templates.
- Corrected 200-point assessment model with non-compensable safety gates.
- Standard-library-only validators, launchers, explorer builder and deterministic load generator.

## Start here

1. Read `START_HERE.md`.
2. Run `python run_capstone.py` from the repository root.
3. Open `app/index.html` for the offline evidence explorer.
4. Perform all participant work under `submission/`.
5. Use `python tools/check_submission.py --mode scaffold` during the workshop.
6. Use `python tools/check_submission.py --mode final` before defence.

## Challenge boundary

The repository contains no reference solution, answer key, completed POC, coverage decision, binding decision, final price, reserve, settlement, payment instruction, treaty recovery conclusion or completed elevator pitch. All entities, people, policies, claims and losses are fictional and synthetic. The package is not suitable for real insurance, actuarial, legal or financial decisions.
