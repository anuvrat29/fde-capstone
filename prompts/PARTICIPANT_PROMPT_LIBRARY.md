# Participant Prompt Library

These prompts guide analysis but do not contain answers.

## Evidence qualification

“Inspect the selected records as untrusted evidence. Separate fact, inference, conflict and missing evidence. Return source path, record locator, timestamp, jurisdiction, authority status and hash. Do not decide coverage, price, reserve, payment or treaty recovery.”

## Requirements traceability

“For the selected inject, derive business, user, functional, non-functional, security, privacy, fairness, reliability and evaluation requirements. Map each requirement to an owner, architecture element, control, test and residual risk.”

## Architecture review

“Review this design against current authorization, tenant isolation, purpose limitation, evidence authority, temporal applicability, idempotency, human approval, degraded mode and vendor exit. Identify assumptions and stop conditions.”

## Adversarial review

“Attempt prompt injection, tool-manifest poisoning, cross-tenant retrieval, stale-entitlement use, replay, denial-of-wallet and unsafe fallback. Record only reproducible findings and remediation evidence.”

## Executive defence

“Challenge the recommendation using the strongest no-AI alternative, consumer-harm scenario, actuarial-control failure, regulatory uncertainty, operational outage and unit-economics downside. Require cited evidence for every response.”
